Broadcast Server (WebSocket Chat System)

A simple real-time broadcast server built using Python and WebSockets.  
This project allows multiple clients to connect to a server and exchange messages instantly in real time, similar to a chat application.

---

Features

- Real-time message broadcasting
- Multiple client connections
- WebSocket-based communication
- Lightweight CLI client
- Handles client disconnects gracefully
- Simple and extensible architecture

---

Tech Stack

- Python
- FastAPI
- WebSockets
- Uvicorn
- asyncio
